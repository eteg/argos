| [`contratos/`](contratos/README.md) | O que a web espera da API: convenções, telas, recursos, operações e fluxos. |

## Como escrever

Português, frases curtas, sem travessão. Regra se cita pelo ID do guia, como `RG08` (status da obra), e não se copia. Tela se cita pelo número do frame no protótipo, como `3.3` (revise o RDO). Na primeira citação de cada seção, o ID vem com uma explicação curta do que ele é.
